# PaginasWeb - Hub de Desarrollo Web 🚀

Un hub centralizado para organizar, desarrollar y mostrar todas tus aplicaciones web y proyectos de desarrollo.

## 📋 Descripción

Este repositorio sirve como un portafolio y espacio de trabajo personal donde puedes:
- Organizar todos tus proyectos web en un solo lugar
- Crear un dominio personalizado para almacenar tus páginas web
- Mostrar tu trabajo de desarrollo de manera profesional
- Experimentar con diferentes tecnologías web

## 🌟 Características

- **Diseño Responsive**: Se adapta a cualquier dispositivo (móvil, tablet, escritorio)
- **Fácil de Personalizar**: Colores, estilos y contenido completamente personalizables
- **Estructura Organizada**: Cada proyecto tiene su propia carpeta y recursos
- **Listo para Desplegar**: Compatible con GitHub Pages, Netlify, Vercel, etc.
- **Proyectos de Ejemplo**: Incluye 3 proyectos de ejemplo para comenzar

## 🚀 Inicio Rápido

1. **Clonar el repositorio**
   ```bash
   git clone https://github.com/ManikTranceART/PaginasWeb.git
   cd PaginasWeb
   ```

2. **Abrir en el navegador**
   - Simplemente abre `index.html` en tu navegador
   - O usa un servidor local:
     ```bash
     python -m http.server 8000
     # Luego visita http://localhost:8000
     ```

3. **Personalizar**
   - Edita `index.html` para actualizar tu información
   - Modifica `styles/main.css` para cambiar colores y estilos
   - Añade tus proyectos en la carpeta `proyectos/`

## 🌐 Despliegue

### GitHub Pages
1. Ve a Settings → Pages
2. Selecciona la rama `main` y carpeta raíz `/`
3. Tu sitio estará en: `https://maniktranceart.github.io/PaginasWeb/`

### Otras Opciones
- **Netlify**: Importa el repositorio y despliega automáticamente
- **Vercel**: Conecta con GitHub y despliega con un clic
- **Hosting Tradicional**: Sube los archivos por FTP
